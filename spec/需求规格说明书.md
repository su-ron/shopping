# 导入证书（Import Certificate）模块 — 需求规格说明书

> 文档版本：v1.0  
> 最后更新：2026-05-06  
> 状态：初稿

---

## 1. 引言

### 1.1 背景

iSAppGallery 应用发布签名配置需要用户导入 .p12 证书文件及相关签名信息，以生成发布所需的签名凭证。本模块作为 SigningConfig 页面的子页面，提供证书导入的完整交互流程。

### 1.2 适用范围

本文档覆盖"导入证书"（Import Certificate / ImportCer）页面的所有功能需求、UI 布局、表单校验规则、前后端交互行为及验收标准。

### 1.3 术语表

| 术语 | 说明 |
|------|------|
| CEF Query | 前端通过 `sendCefQuery` 与后端 Java 通信的异步消息机制 |
| PKCS12 / .p12 | 包含私钥和证书的密钥存储文件格式 |
| CSR | Certificate Signing Request，证书签名请求文件 |
| CN | Common Name，通用名称（证书主题中的姓名字段） |
| KeyStore | 密钥库，用于存储密钥条目和证书 |

---

## 2. 总体描述

### 2.1 页面入口

由 SigningConfig 页面的下拉框选择 "导入证书" 后进入。

### 2.2 页面名称

- 中文：导入证书
- 英文：Upload Product（页面标题）
- 组件名：`ImportCer`

### 2.3 用户角色

iSAppGallery 应用发布者，需要为应用配置发布签名。

### 2.4 页面定位

```
SigningConfig 页面
  └─ 下拉选择"导入证书"
       └─ ImportCer 页面（当前模块）
            ├─ 填写证书信息
            ├─ 点击 Next → 调用后端生成证书
            └─ 点击 Cancel → 返回 SigningConfig
```

### 3.1 页面布局

### 3.2 字段定义

| # | 字段 | key | 必填 | 默认值 | 输入类型 | 说明 |
|---|------|-----|------|--------|----------|------|
| 1 | Key store name | p12Name | ✅ | - | 文本输入 | .p12 文件名，含后缀 |
| 2 | Save path (p12) | p12Path | ✅ | - | 文本 + 文件夹选择 | 保存路径，通过 IntelliJ 原生选择器 |
| 3 | Key store password | password | ✅ | - | 密码输入 | 复杂度要求见 3.3.2 |
| 4 | Confirm password | confirmPassword | ✅ | - | 密码输入 | 必须与 password 一致 |
| 5 | Alias | keyAlias | ✅ | - | 文本输入 | 见 3.3.3 |
| 6 | Validity | validity | - | 25 | 数字输入(上下调节) | 有效期（年） |
| 7 | First and last name | firstName | - | (alias) | 文本输入 | CN，为空时取 alias |
| 8 | Organizational unit | orgUnit | - | - | 文本输入 | OU |
| 9 | Organization | organization | - | - | 文本输入 | O |
| 10 | City or locality | city | - | - | 文本输入 | L |
| 11 | State or province | province | - | - | 文本输入 | ST |
| 12 | Country code | countryCode | - | - | 文本输入(2字符) | C，2位大写字母 |
| 13 | CSR file name | CSRName | ✅ | - | 文本输入 | .csr 文件名 |
| 14 | Save path (CSR) | csrPath | ✅ | - | 文本 + 文件夹选择 | CSR 保存路径 |

### 3.3 表单校验规则

#### 3.3.1 Key store name (p12Name)
- 必填
- 只能包含：字母（a-z, A-Z）、数字（0-9）、连字符（-）、下划线（_）、点（.）
- 必须以 `.p12` 结尾
- 正则：`/^[a-zA-Z0-9_.-]+\.p12$/`

#### 3.3.2 密码 (password)
- 必填
- 最小长度 6 个字符
- 必须同时包含以下四类字符：
  - 小写字母 a-z
  - 大写字母 A-Z
  - 数字 0-9
  - 特殊字符：`~!@#$%^&*()-_=+|[{}];:'",.<>/?`
- 正则：`/(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[~!@#$%^&*()\-_=+|[\]{};:'",.<>/?`])/`

#### 3.3.3 Alias (keyAlias)
- 必填
- 不允许包含空格

#### 3.3.4 确认密码 (confirmPassword)
- 必填
- 必须与 password 完全一致

#### 3.3.5 路径字段 (p12Path, csrPath)
- 必填
- 不允许为空字符串
- 前端做基本合法性校验，后端做最终的路径存在性/可写性校验

#### 3.3.6 Validity (validity)
- 非必填（出现在 Advance Setting 中）
- 如果填写，必须是正整数
- 输入框宽度约 100px，带上下调节按钮且始终显式显示

#### 3.3.7 高级设置字段 (firstName, orgUnit, organization, city, province, countryCode)
- 均不强制填写
- 当 firstName 为空时，前端自动取 keyAlias 作为默认值发送给后端

#### 3.3.8 CSR file name (CSRName)
- 必填

### 3.4 文件选择功能

#### 3.4.1 P12 路径选择
- 点击 📁 图标
- 通过 CEF Query 调用后端 Java 代码
- 后端调用 IntelliJ 原生 `FileChooser.chooseFile()`（目录选择器）
- 选择后路径回填到输入框

#### 3.4.2 CSR 路径选择
- 同上，点击 CSR 路径旁的 📁 图标
- 通过 CEF Query 调用后端
- 选择目录后回填路径

### 3.5 Advance Setting 交互

- 默认收起状态
- 点击展开标题行可展开/收起
- 展开时，页面高度向下延伸
- 收起时，页面高度随之缩减
- 展开/收起图标使用 ▶/▼ 箭头

### 3.6 按钮行为

#### 3.6.1 Next 按钮
- 点击后立即执行全部字段校验
- 校验失败 → 在对应字段下方显示错误提示，阻止提交
- 校验成功 → 构造 `ImportCertificatePayload`，发起 CEF Query 请求
- 请求期间按钮显示 loading 状态
- 后端返回成功 → 进入下一步
- 后端返回失败 → message.error 提示错误信息

#### 3.6.2 Cancel 按钮
- 返回 SigningConfig 页面（上一页）

### 3.7 帮助提示（Tooltip）

各字段后的 (?) 图标：

| 位置 | 说明 |
|------|------|
| p12Name | P12 文件命名规则说明 |

| CSR file | CSR 用途说明 |

## 4. 前后端交互

### 4.1 通信机制

采用 CEF Query 异步通信方式：
```
前端 sendCefQuery(cfg)
  → CEF Bridge
  → Java CefQueryHandler.onQuery(data, callback)
  → callback.success(json)
  → 前端 cfg.success(data) 回调
```

### 4.2 交互总览

| Action | 方向 | 触发时机 | Handler |
|--------|------|----------|---------|
| SelectFilePath | 前端→后端 | 点击 📁 图标 | `SelectFilePathHandler` |
| ImportCertificate | 前端→后端 | 点击 Next 按钮 | `ImportCertificateHandler` |

### 4.3 SelectFilePath 协议

请求：
```json
{ "extensions": [".p12"], "title": "Select .p12 file" }
```

响应：
```json
{ "path": "D:/selected/folder" }
// 用户取消时：
{ "path": "" }
```

### 4.4 ImportCertificate 协议

请求 payload（`ImportCertificatePayload`）：
```json
{
  "p12Name": "mykeystore.p12",
  "p12Path": "D:/certs/",
  "password": "MyP@ss123",
  "keyAlias": "myalias",
  "validity": 25,
  "firstName": "John Doe",
  "orgUnit": "Engineering",
  "organization": "MyCompany",
  "city": "Beijing",
  "province": "Beijing",
  "countryCode": "CN",
  "CSRName": "mycsr.csr",
  "csrPath": "D:/certs/"
}
```

响应成功（`CefResponse<ImportCertificateResult>`）：
```json
{
  "success": true,
  "data": {
    "certificateId": "cert-1712345678",
    "validFrom": "2026-01-01",
    "validTo": "2031-01-01"
  }
}
```

响应失败：
```json
{
  "success": false,
  "error": {
    "code": "CERT_INVALID_INPUT",
    "message": "Key store name is required"
  }
}
```

### 4.5 错误码定义

| code | 含义 | 前端行为 |
|------|------|----------|
| `CERT_INVALID_PASSWORD` | 密码错误 | message.error 提示 |
| `CERT_PATH_NOT_WRITABLE` | 路径不可写 | message.error 提示 |
| `CERT_GENERATION_FAILED` | 证书生成失败 | message.error 提示 |
| `CERT_FILE_EXISTS` | 文件已存在 | 确认是否覆盖 |
| `CERT_INVALID_INPUT` | 输入参数非法 | message.error + 字段级高亮 |
| `CERT_INTERNAL_ERROR` | 后端内部错误 | 通用错误提示 |

### 4.6 安全注意事项

1. **密码不持久化**：请求完成后，前端应清除内存中的密码字段
2. **不记录日志**：payload 中的 password 字段不应出现在 console.log 或后端日志中
3. **不缓存敏感数据**：表单数据（含密码）不缓存到 localStorage/sessionStorage
4. **路径校验**：前端做基本合法性校验，后端做最终的存在性/可写性校验

## 5. 非功能需求

### 5.1 UI 规范

| 项目 | 规格 |
|------|------|
| 标签宽度 | 170px |
| Validity 输入框宽度 | 100px |
| 背景色 | 透明（暗色主题） |
| 字体颜色 | #e6e6e6 |
| 边框颜色 | #ffffff |
| 输入框高度 | 32px |
| 帮助图标 | 16x16px |
| 文件夹图标 | 16x16px |
| 必填标记 | 红色星号 `*`（#ff4d4f） |
| 错误提示颜色 | #ff4d4f |
| 间距 | 输入框与左侧标签间距较小 |

### 5.2 页面行为

- 页面高度由内容决定，不固定尺寸
- 展开 Advance Setting 时页面向下延伸，收起时缩减
- Alias 行缩进 3 个字符宽度
- 帮助图标统一占位（无内容的渲染不可见占位符以保持对齐）

### 5.3 国际化

所有文本通过 `getMessage(key)` 获取，集中管理在 `internationalization.ts` 中。

## 6. 验收标准

### 6.1 基础功能

- [ ] 页面正常加载，布局符合设计稿
- [ ] 所有字段可输入
- [ ] 标题为 "Upload Product"

### 6.2 文件选择

- [ ] 点击 📁 图标可打开 IntelliJ 原生文件夹选择器
- [ ] 路径正确回填到输入框
- [ ] 用户取消时无变化

### 6.3 表单校验

- [ ] 必填项为空时阻止提交并显示错误
- [ ] p12Name 格式校验（字母/数字/-/_/./.p12）
- [ ] 密码复杂度校验（大小写+数字+特殊字符）
- [ ] 密码一致性校验
- [ ] Alias 不允许空格
- [ ] 错误提示清晰显示

### 6.4 交互行为

- [ ] Next 校验通过 → 发起 CEF Query → 成功进入下一步
- [ ] Next 校验失败 → 阻止提交，显示错误
- [ ] Cancel → 返回上一页
- [ ] Advance Setting 可展开/收起
- [ ] Validity 默认值为 25，上下调节按钮可操作

### 6.5 异常处理

| 场景 | 预期行为 |
|------|----------|
| 文件不存在 | 后端返回错误提示 |
| 路径非法 | 后端返回错误提示 |
| 密码错误 | 后端返回 CERT_INVALID_PASSWORD |
| 后端异常 | 返回 CERT_INTERNAL_ERROR |
| 网络断开 | failure 回调触发 |
