# Upload Product 页面需求说明（完整PRD）

---

## 1. 背景说明

该页面用于导入证书文件（.p12）及相关签名信息，用于 iSAppGallery 应用发布签名配置。

用户需完成证书导入、密钥配置及 CSR 文件生成路径配置，以生成发布所需的签名凭证。

---

## 5. 功能说明

### 5.1 文件选择

📁 P12 路径选择
点击 📁 图标
打开本地文件选择器
选择 .p12 文件
自动填充路径到输入框
📁 CSR 路径选择
点击 📁 图标

### 5.2 表单校验（⚠️核心补充）

1️⃣ Key store name
必填
只能包含：字母、数字、-、_和.

2️⃣ 密码
必填

**1. Lowercase letters: a-z<br>**
2. Uppercase letters: A-Z<br>
3. Digits: 0-9<br>
4. Special characters: \~!@#\$%^&\*()-\_=+|[{}];:'",.<>/?\`,
3️⃣ 确认密码
必须与 password 一致
4️⃣ Alias
必填
不允许空格
5️⃣ 路径
必填
必须是合法路径
不允许为空字符串

6.高级设置部分：

Validity默认值为25

其他值不强制填写，在没有填写的情况下，First and last name:与alias的值保持一致，如果有填写，则取填写的值

## 8. 前后端交互方案（CEF Query）

### 8.1 通信机制概述

前端通过 `sendCefQuery` 向 CEF 后端发送异步请求，后端处理后返回响应。流程如下：

```
用户点击 Next
  → 前端校验表单
  → 校验通过 → 构造 CefQueryCfg → sendCefQuery(cfg)
  → 后端处理 → 返回响应
  → 前端根据结果：成功则 onNext()，失败则展示错误
```

当前sendCefQuery函数已经实现，具体使用如下所示

示例：

### 8.3 ImportCer 专用请求/响应契约

#### 请求（payload）

```typescript
interface ImportCertificatePayload {
  /** 证书文件参数字段 */
  p12Name: string;         // 自定义 .p12 文件名（含 .p12 后缀）
  p12Path: string;         // .p12 文件保存路径（绝对路径）
  password: string;        // keystore 密码
  keyAlias: string;        // 别名

  /** 证书主题（subject） */
  validity: number;        // 有效期（年）
  firstName: string;       // 姓名（CN）
  orgUnit: string;         // 组织单位（OU）
  organization: string;    // 组织（O）
  city: string;            // 城市/ locality（L）
  province: string;        // 省/州（ST）
  countryCode: string;     // 国家代码（C），2位大写字母

  /** CSR 文件参数 */
  CSRName: string;         // CSR 文件名（含 .csr 后缀）
  csrPath: string;         // CSR 文件保存路径（绝对路径）
}
```

#### 响应（data）

```typescript
interface ImportCertificateResult {
  /** 生成的证书指纹或唯一标识 */
  certificateId?: string;
  /** 证书有效期信息 */
  validFrom?: string;
  validTo?: string;
}
```

> 注：前端仅校验表单格式，后端需校验密码是否正确、路径是否可写、证书是否可正常生成。

### 8.5 错误码定义（建议后端统一）


| code                     | 含义         | 前端行为                     |
| ------------------------ | ------------ | ---------------------------- |
| `CERT_INVALID_PASSWORD`  | 密码错误     | `message.error` 提示         |
| `CERT_PATH_NOT_WRITABLE` | 路径不可写   | `message.error` 提示         |
| `CERT_GENERATION_FAILED` | 证书生成失败 | `message.error` 提示         |
| `CERT_FILE_EXISTS`       | 文件已存在   | 可选项：确认是否覆盖         |
| `CERT_INVALID_INPUT`     | 输入参数非法 | `message.error` + 字段级高亮 |
| `CERT_INTERNAL_ERROR`    | 后端内部错误 | 通用错误提示                 |

### 8.6 安全注意事项

1. **密码不持久化**：请求完成后，前端应清除内存中的密码字段
2. **不记录日志**：payload 中的 password 字段不应出现在前端 console.log 或后端日志中
3. **不缓存敏感数据**：表单数据（含密码）不应缓存到 localStorage/sessionStorage
4. **路径校验**：前端只做基本路径合法性校验，后端做最终的路径存在性/可写性校
