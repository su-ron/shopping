# Upload Product 页面需求说明（完整PRD）

---

## 1. 背景说明

该页面用于导入证书文件（.p12）及相关签名信息，用于 iSAppGallery 应用发布签名配置。

用户需完成证书导入、密钥配置及 CSR 文件生成路径配置，以生成发布所需的签名凭证。

---

## 2. 页面概述

### 2.1 页面名称
导入证书

### 2.2 页面入口
由SigningConfig页面点击下拉框选择{getMessage('uploadProduct.signingConfig.selectCertificate')}进入的

---

## 3. 页面布局

```
------------------------------------------------------------
                         Upload Product
------------------------------------------------------------
* Key store name (*.p12): [ input field    ] (?)
* Select file save path:  [ input field 📁 ]
                          File will be create in:input field
* Key store password:     [ input field    ]
* Confirm password:       [ input field    ]
Key---------------------------------------------------------
    * Alias: [ input field               📁] (?)
    >Advance Setting----------------------------------------
     Validity(years):     [ 数字   （可以上下调节） ]

```

---

## 4. 字段说明

| 字段                 | 必填 | 说明               |
| ------------------ | -- | ---------------- |
| Key store name     | ✅  | 用户自定义 `.p12` 文件名 |
| Save path（p12）     | ✅  | `.p12` 文件保存路径    |
| Key store password | ✅  | keystore 密码      |
| Confirm password   | ✅  | 二次确认密码           |
| Alias              | ✅  | key 别名           |
| CSR file name      | ✅  | CSR 文件名称         |
| Save path（CSR）     | ✅  | CSR 文件保存路径       |


---
## 5. 功能说明
### 5.1 文件选择
📁 P12 路径选择
点击 📁 图标
打开本地文件选择器
选择 .p12 文件
自动填充路径到输入框
📁 CSR 路径选择
点击 📁 图标
选择保存目录（或文件名）
自动回填路径
### 5.2 表单校验（⚠️核心补充）
1️⃣ Key store name
必填
只能包含：字母、数字、-、_
必须以 .p12 结尾
2️⃣ 密码
必填
长度 ≥ 6
3️⃣ 确认密码
必须与 password 一致
4️⃣ Alias
必填
不允许空格
5️⃣ 路径
必填
必须是合法路径
不允许为空字符串
### 5.3 交互逻辑
🔄 页面初始化
默认字段为空
不自动加载历史数据（除非有缓存需求）
🔘 Next 按钮

点击后：

1. 校验所有字段
2. 如果失败 → 显示错误提示
3. 如果成功 → 触发 CEF 请求
   🔙 Cancel 按钮
   返回上一页（SigningConfig）
   5.4 帮助提示（Tooltip）
   (?) icon 说明：
   位置	内容
   p12 name	说明文件命名规则
   Alias	说明 alias 用途
   CSR	说明 CSR 用途
