---

## 1. 背景说明

该页面用于导入证书文件（.p12）及相关签名信息，用于 iSAppGallery 应用发布签名配置。

用户需完成证书导入、密钥配置及 CSR 文件生成路径配置，以生成发布所需的签名凭证。

## 8. 前后端交互方案（CEF Query）

### 8.1 通信机制概述

前端通过 `sendCefQuery` 向 CEF 后端发送异步请求，后端处理后返回响应。流程如下：

```
用户点击 Next
  → 前端校验表单
  → 校验通过 → 构造 CefQueryCfg → sendCefQuery(cfg)
  → 后端处理 → 返回响应
  → 前端根据结果：成功则 onNext()，失败则展示错误
```

### 8.2 CefQueryCfg 接口定义

建议在 `cef/CefQueryCfg.ts` 中定义统一的 Query 配置类型：

```typescript
// ============ 统一基础类型 ============

/** CEF Query 请求配置 */
interface CefQueryCfg {
  /** 请求唯一标识，用于追踪 */
  requestId?: string;
  /** 动作名称，后端根据 action 分发处理 */
  action: string;
  /** 请求体 */
  payload: Record<string, unknown>;
  /** 超时时间（毫秒），默认 30000 */
  timeout?: number;
  /** 是否持久连接（用于推送场景），默认 false */
  persistent?: boolean;
}

/** CEF Query 响应 */
interface CefQueryResponse<T = unknown> {
  /** 是否成功 */
  success: boolean;
  /** 响应数据 */
  data?: T;
  /** 错误信息 */
  error?: {
    code: string;
    message: string;
  };
}
```

### 8.3 ImportCer 专用请求/响应契约

#### 请求（payload）

```typescript
interface ImportCertificatePayload {
  /** 证书文件参数字段 */
  p12Name: string;         // 自定义 .p12 文件名（含 .p12 后缀）
  p12Path: string;         // .p12 文件保存路径（绝对路径）
  password: string;        // keystore 密码
  keyAlias: string;        // 别名

  /** 证书主题（subject） */
  validity: number;        // 有效期（年）
  firstName: string;       // 姓名（CN）
  orgUnit: string;         // 组织单位（OU）
  organization: string;    // 组织（O）
  city: string;            // 城市/ locality（L）
  province: string;        // 省/州（ST）
  countryCode: string;     // 国家代码（C），2位大写字母

  /** CSR 文件参数 */
  CSRName: string;         // CSR 文件名（含 .csr 后缀）
  csrPath: string;         // CSR 文件保存路径（绝对路径）
}
```

#### 响应（data）

```typescript
interface ImportCertificateResult {
  /** 生成的证书指纹或唯一标识 */
  certificateId?: string;
  /** 证书有效期信息 */
  validFrom?: string;
  validTo?: string;
}
```

> 注：前端仅校验表单格式，后端需校验密码是否正确、路径是否可写、证书是否可正常生成。

### 8.4 handleNext 实现建议

```typescript
const handleNext = async (): Promise<void> => {
  // 1. 校验所有字段
  if (!validateForm()) {
    return;
  }

  // 2. 构造 CEF 请求
  setLoading(true);
  try {
    const cfg: CefQueryCfg = {
      action: 'importCertificate',
      payload: {
        p12Name: form.p12Name,
        p12Path: form.p12Path,
        password: form.password,
        keyAlias: form.keyAlias,
        validity: form.validity,
        firstName: form.firstName,
        orgUnit: form.orgUnit,
        organization: form.organization,
        city: form.city,
        province: form.province,
        countryCode: form.countryCode,
        CSRName: form.CSRName,
        csrPath: form.csrPath,
      },
    };

    const response = await sendCefQuery<ImportCertificateResult>(cfg);

    if (response.success) {
      // 3. 成功 → 进入下一步
      onNext();
    } else {
      // 4. 失败 → 显示后端错误
      message.error(response.error?.message || 'Import failed');
    }
  } catch (err) {
    message.error('Network or system error occurred');
  } finally {
    setLoading(false);
  }
};
```

### 8.5 错误码定义（建议后端统一）

| code | 含义 | 前端行为 |
|------|------|---------|
| `CERT_INVALID_PASSWORD` | 密码错误 | `message.error` 提示 |
| `CERT_PATH_NOT_WRITABLE` | 路径不可写 | `message.error` 提示 |
| `CERT_GENERATION_FAILED` | 证书生成失败 | `message.error` 提示 |
| `CERT_FILE_EXISTS` | 文件已存在 | 可选项：确认是否覆盖 |
| `CERT_INVALID_INPUT` | 输入参数非法 | `message.error` + 字段级高亮 |
| `CERT_INTERNAL_ERROR` | 后端内部错误 | 通用错误提示 |

### 8.6 安全注意事项

1. **密码不持久化**：请求完成后，前端应清除内存中的密码字段
2. **不记录日志**：payload 中的 password 字段不应出现在前端 console.log 或后端日志中
3. **不缓存敏感数据**：表单数据（含密码）不应缓存到 localStorage/sessionStorage
4. **路径校验**：前端只做基本路径合法性校验，后端做最终的路径存在性/可写性校验
